Créer mon MULTIPASS

Votre espace personnel sur cette station : vos photos, vos proches et vos échanges, chiffrés et lisibles par vous seul.

Vérification de la station…

Il est écrit dans le journal de la station au démarrage (terminal, ou journalctl --user -u astroportd) : il prouve que vous avez la main sur la machine.

La station vous crée une adresse du type léa-x7k2p9@…. C’est votre identifiant : elle ne sert pas à recevoir des courriers. Sans email, gardez bien la carte de secours affichée ensuite : elle sera votre seul moyen de récupération.

Votre MULTIPASS est prêt

Pour vous connecter, sur ordinateur comme sur téléphone, il vous suffit de deux choses :

Votre identifiant
Votre code PASS

Notez votre code PASS maintenant : il ne sera plus jamais affiché.

Votre carte de secours

Votre clé est découpée en 3 morceaux ; 2 suffisent pour tout retrouver. Celui-ci est le vôtre : imprimez-le et rangez-le dans un tiroir. Le deuxième reste sur la station, le troisième sera confié à l’ami qui gardera votre sauvegarde. Seul, ce morceau ne sert à rien : même volé, il n’ouvre pas votre compte.

Détails techniques (facultatif)

Vos clés sont gardées par la station : vous n’en avez pas besoin au quotidien. Elles figurent dans le fichier à télécharger.

Votre quartier (facultatif)

Indiquez où vous vivez pour recevoir les nouvelles de votre quartier et y publier. La station ne garde qu’une position approchée, à environ 1 km : jamais votre adresse.
